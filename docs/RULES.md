# 休闲八球规则

本项目采用简化的休闲八球规则，不宣称完全实现某一赛事标准。规则实现以 `shared/rules.ts` 为准，测试在 `test/rules.test.ts`。

- 1–7 号为全色球，9–15 号为花色球，8 号为黑八，0 号为白球。
- 开球不分组。之后开放球台时，合法一杆只打进一种球组，则分配该组；同时打进两组时仍保持开放。
- 合法打进本组球可继续击球，否则交换回合。打进对方球本身不必然犯规，先触球及其他条件仍需合法。
- 分组后先碰本组球；清完本组球后须先碰黑八。开放球台不可先碰黑八。
- 白球落袋、没有碰到任何目标球、错误的第一接触、触球后既无进球也无球碰库，属于普通犯规，对方获得自由球。
- 自由球可在合法台面位置放置，不可与球重叠、越界或放在袋口。放置后点击确认。
- 开球需有目标球入袋，或至少四颗不同目标球碰库。开球进黑八会重新摆球，不直接判胜；若同时犯规则对方开球。
- 非开球时，只有在出杆前已经清完本组球，并合法打进黑八才获胜。提前进黑八或进黑八时犯规判负。
- 每回合 60 秒，超时交换回合并给对方自由球。无指定袋口玩法。
- 联网版意外断线最多保留 60 秒；主动离开进行中对局判负。服务重启中断对局，不产生虚假胜者。
- 同屏 Demo 使用相同的球与判罚规则；两人轮流操作一个页面，没有联网恢复，刷新重新开始。
